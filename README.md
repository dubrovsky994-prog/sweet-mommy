# Sweet Mommy — демо-магазин

Демо-сайт Sweet Mommy для Пензы: каталог, корзина, доставка, онлайн-оплата, MAX-бот и юридические страницы.

## Запуск

Нужен Node.js 18+.

```powershell
node server.js
```

Открыть: `http://127.0.0.1:3000`

Без ключей YooKassa сайт работает в демо-режиме и не списывает деньги.

## MAX и ЮKassa

Подробная инструкция находится в [PRODUCTION_SETUP.md](PRODUCTION_SETUP.md). Заявки из формы и заказы отправляются в MAX через API.

Для ЮKassa при подтверждённой схеме для НПД:

```powershell
$env:YOO_KASSA_SHOP_ID="..."
$env:YOO_KASSA_SECRET_KEY="..."
$env:YOO_KASSA_RETURN_URL="https://ваш-домен.ru/payment/success"
$env:YOO_KASSA_TAX_MODE="self_employed"
node server.js
```

В режиме `self_employed` текущая заготовка не передаёт чек автоматически через API ЮKassa. Порядок регистрации дохода и отправки чека нужно подтвердить для вашего статуса и вида деятельности до запуска.

Для MAX:

```powershell
$env:MAX_BOT_TOKEN="..."
$env:MAX_RECIPIENT_ID="..."
$env:MAX_RECIPIENT_TYPE="user"
```

Секреты хранятся только на сервере, не в HTML и не в `app.js`.
Файл `max.config.json` содержит секретный токен и не должен попадать в публичный архив; для примера есть `max.config.example.json`.

## Перед публикацией

1. Заменить реквизиты и контакты продавца в `legal/requisites.html`.
2. Проверить тексты оферты, доставки, возвратов и политики конфиденциальности.
3. Проверить товары, цены, фото и закреплённые тарифы доставки: Пенза/район и Сердобск — до 5 км 250 ₽, 5–10 км 350 ₽, 10–15 км 500 ₽.
4. Подключить домен с HTTPS.
5. Для НПД подтвердить по фактическому составу композиций, что это собственная продукция, а не перепродажа готовых товаров.
6. Настроить webhook YooKassa для финального статуса оплаты и повторных уведомлений в MAX.
