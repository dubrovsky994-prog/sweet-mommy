# Подключение MAX и ЮKassa

## 1. MAX-бот

Публичная ссылка бота для кнопки сайта: `https://max.ru/id583607809709_bot`.

Для упрощённого подключения можно вставить токен только в локальный файл `max.config.json`, открыть бота по публичной ссылке, нажать «Начать», написать ему `тест` и запустить `connect-max.bat`. Скрипт попробует найти последний диалог и сохранит получателя автоматически. Файл с токеном добавлен в `.gitignore`.

Если сайт запускается на компьютере с проблемой доверия к сертификату MAX, скрипт использует официальный совместимый адрес `https://platform-api.max.ru`. На рабочем HTTPS-хостинге можно указать в конфигурации `api_base: "https://platform-api2.max.ru"` согласно актуальной документации MAX.

1. Создайте или откройте бота в разделе MAX для разработчиков/для бизнеса.
2. В расширенных настройках получите токен бота.
3. Добавьте бота в рабочий чат или укажите пользователя, которому бот может отправлять сообщения.
4. Получите `user_id` или `chat_id` получателя.
5. Запустите сервер с переменными:

```powershell
$env:MAX_BOT_TOKEN="токен_бота"
$env:MAX_RECIPIENT_ID="ID_пользователя_или_чата"
$env:MAX_RECIPIENT_TYPE="user"
```

Для группового чата используйте `MAX_RECIPIENT_TYPE=chat`. Токен нельзя размещать в HTML, `app.js` или отправлять в переписке.

## 2. ЮKassa и режим НПД

1. Подтвердите в личном кабинете ЮKassa, доступна ли выбранная схема подключения для вашего статуса и вида деятельности.
2. Подготовьте данные продавца, настоящий домен сайта, контакты и страницы оферты, доставки, возвратов, конфиденциальности и реквизитов.
3. Пройдите проверку магазина и получите `shopId` и секретный ключ только после одобрения.
5. Запустите сервер:

```powershell
$env:YOO_KASSA_SHOP_ID="shopId"
$env:YOO_KASSA_SECRET_KEY="секретный_ключ"
$env:YOO_KASSA_RETURN_URL="https://ваш-домен.ru/payment/success"
$env:YOO_KASSA_TAX_MODE="self_employed"
node server.js
```

В режиме `self_employed` текущая заготовка создаёт платёж без автоматической передачи чека в ЮKassa. После успешной оплаты доход и чек нужно оформить по фактическому порядку для НПД и отправить чек покупателю. Точную схему подтвердите в ЮKassa и ФНС до запуска: этот проект не заменяет кассовую и налоговую настройку.

## 3. Если перейти на ИП

Для автоматической фискализации можно использовать ИП и онлайн-кассу/решение ЮKassa для чеков:

```powershell
$env:YOO_KASSA_TAX_MODE="company"
$env:YOO_KASSA_VAT_CODE="1"
```

Перед запуском нужно подтвердить в личном кабинете ЮKassa режим налогообложения и ставку НДС. Значение `YOO_KASSA_VAT_CODE` нельзя оставлять демонстрационным без проверки.

## Важное ограничение НПД

Для НПД нужно отдельно подтвердить, что фактические композиции относятся к собственной продукции, а не к перепродаже чужих товаров. Для Sweet Mommy это особенно важно проверить по цветам, упаковке, сладостям и готовым покупным товарам. До запуска получите подтверждение по вашей модели у бухгалтера или в ФНС.
