# Заявки и заказы в MAX

Сайт отправляет в MAX:

- заявки из формы контактов через `POST /api/contact-request`;
- заказы из оформления через `POST /api/create-payment`.

В сообщение о заказе входят номер заказа, покупатель, получатель, адрес, дата и интервал доставки, состав, сумма и статус оплаты. Оплата на сайте остаётся только онлайн — картой или через СБП.

Перед запуском сервера задайте переменные окружения:

```powershell
$env:MAX_BOT_TOKEN="токен_бота"
$env:MAX_RECIPIENT_ID="id_получателя_или_чата"
$env:MAX_RECIPIENT_TYPE="user"
node server.js
```

Для группового чата укажите `$env:MAX_RECIPIENT_TYPE="chat"`. Без этих переменных сайт работает в демо-режиме и честно возвращает `max_not_configured`, не выдавая доставку в MAX за выполненную.

Для рабочего проекта токен и ID нужно хранить только на сервере, не в `app.js` и не в открытом HTML. После подключения YooKassa желательно добавить webhook: тогда в MAX можно будет отправлять отдельное уведомление именно после подтверждения успешной оплаты, а не только после создания платёжной сессии.
